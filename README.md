# 🌧️ Rainfall Prediction

## Project Description

Rainfall Prediction is a Machine Learning project that predicts whether rainfall is likely to occur based on weather conditions.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib
- Streamlit

## Machine Learning Algorithms

1. Logistic Regression
2. Decision Tree
3. Random Forest
4. K-Nearest Neighbors

## Input Features

- Minimum Temperature
- Maximum Temperature
- Rainfall
- Humidity at 9 AM
- Humidity at 3 PM
- Pressure at 9 AM
- Pressure at 3 PM
- Temperature at 9 AM
- Temperature at 3 PM
- Wind Speed at 9 AM
- Wind Speed at 3 PM

## Output

The system predicts:

- Rain
- No Rain

It also displays the predicted rainfall probability.

## Application

The project uses Streamlit to create a web-based Machine Learning application.
